# Мультимедиа Инструменты 🎬

Локальный набор инструментов для работы с медиа, который работает прямо в браузере. 
Все файлы обрабатываются на вашем компьютере и никуда не загружаются в интернет.

## 📖 О проекте

Этот сайт появился из простой потребности: во время монтажа видео часто нужно быстро вырезать звук, убрать фон с картинки или замазать лишний объект. Вместо того чтобы каждый раз искать онлайн-сервисы (с их лимитами и загрузкой файлов в сеть), было решено собрать все нужные инструменты в одном локальном приложении.

Проект разработан для личных нужд и не претендует на звание коммерческого продукта, но хорошо справляется со своими задачами.

## 🧰 Функционал

*   **Удаление фона:** Удаляет фон с изображений с помощью нейросети (ISNet). Работает полностью офлайн.
*   **Вырезать звук:** Извлекает аудиодорожку из видеофайлов (MP4, MOV, MKV и др.) и конвертирует в M4A или MP3.
*   **Конвертер:** Быстро меняет формат изображений (JPG, PNG, WebP, GIF, JFIF) в JPG или PNG.
*   **Ретушь:** Позволяет закрашивать дефекты цветом взятым пипеткой или выбраным в палитре, делать части изображения прозрачными.

## 🧩 Как запустить

**Шаг 1. Установите Node.js**
Убедитесь, что на вашем компьютере установлен [Node.js](https://nodejs.org/) (рекомендуется версия 18 или выше).

**Шаг 2. Установите зависимости**
* Для Windows (автоматически): дважды кликните по файлу `install.bat`, и он установит всё автоматически.
* Вручную (для любой ОС): откройте терминал в папке с проектом и выполните команду
```bash
npm install
```

**Шаг 3. Запустите сервер**
* Для Windows (автоматически): Дважды кликните по файлу `Start Video Tools.bat`. Сервер запустится, и браузер откроет сайт.
* Вручную (для любой ОС): Выполните в терминале команду 
```bash 
node server.js
``` 
и откройте в браузере страницу `http://localhost:3000`.

**Важно!** 

Не пытайтесь открыть `index.html` просто двойным кликом мыши. Сайт должен запускаться только через локальный сервер (командой `node server.js` или через `Start Video Tools.bat`), иначе часть функций (например, вырезание звука) не будет работать из-за политик безопасности браузера.  
> *Проект разработан и протестирован на Windows, но может быть запущен на любой ОС, где установлен Node.js.*
